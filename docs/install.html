DS203 WebScope

Custom firmware that adds a USB serial port to the Miniware DS203, plus a browser UI that talks to it over Web Serial.

Experimental. Tested on a single unit. Only for HW 2.81 or newer (it is a patch on top of Wildcat V6.5). Flashing uses the built-in DFU disk, which is normally recoverable, but you do this at your own risk. Keep the original firmware for your hardware before you start.

1. Download

app1-cdc.hex SHA-256

Built with Arm GNU Toolchain 15.3. It is not byte-identical to upstream Wildcat builds.

2. Back up a way out

Get the original app1.hex for your hardware revision from the Wildcat repository (WildcatV6.5 for HW 2.81+) and keep it. If the new firmware misbehaves, flash that file the same way.

3. Flash with DFU

  1. Power the DS203 off.
  2. Hold the >|| button (button 1) and switch it on while holding. Keep holding.
  3. Connect it to the computer with a data USB cable. A drive named like DFU V3_xx appears.
  4. Copy app1-cdc.hex onto the drive, renamed to app1.hex: 
    cp app1-cdc.hex "/Volumes/DFU V3_46_C/app1.hex"
  5. The drive disappears and comes back with APP1.RDY (success) or APP1.ERR (failed).
  6. Power the scope off and on again, normally.

If you get .ERR, the DFU version may reject big files. The Wildcat install notes describe a split .ADR/.BIN method.

4. Use it

  1. On the scope, open the T-BASE menu (long press button 4, ^) and set the trigger mode to AUTO. In TrOFF (SCAN) the time base and mode cannot be changed over USB.
  2. Open the WebScope UI in Chrome or Edge, press Connect, and pick the DS203 CDC port.
  3. No scope at hand? Press Demo to try the interface with synthetic signals.

Known issues

  • Capturing while the scope is running times out; the UI works around it with STOP, capture, RUN.
  • The USB device sometimes failed to enumerate after boot or replug during development. The cause is not found yet. If it does not show up, reflash or replug.
  • Values are raw 8-bit ADC codes. Volts per division and sample rates are not calibrated.

Source

Serial protocol. The firmware changes are published as a patch (firmware/usb-cdc.patch) against Wildcat commit ef08bdb in the repository.
